# Screen-watcher

Aplikacja działająca w tle, przeznaczona do przechwytywania i udostępniania ekranu. Projekt został stworzony w języku Python i wykorzystuje technologię WebRTC do płynnego przesyłania strumienia wideo.

## Funkcjonalności

* Przechwytywanie obrazu z ekranu w czasie rzeczywistym.
* Komunikacja i przesyłanie strumienia wideo z użyciem protokołu WebRTC.
* Działanie jako proces w tle.

## Technologie

* Język: Python
* Protokół: WebRTC
